# Contributing

Please open an issue with the project version, OS/Python/dependency versions, exact command, configuration and a minimal reproducible observation. Do not attach patient records, private correspondence or confidential datasets.

For scientific changes, distinguish publication data, source-cell transfer, numerical results and hypotheses. Record units, species/cells, provenance, uncertainty and the predicted consequence before testing. Include negative outcomes. Numerical balances and human calibration are separate tests.

Keep each new output in a new directory. Preserve earlier source/result provenance, checkpoints and scientific disagreements. Do not silently change a historical default or relabel a scenario grid as a measured interval. Submit original software contributions under the project's AGPL-3.0-only license, with appropriate attribution and permission to contribute. External code must have compatible licensing; retain its notices. See [licensing scope](docs/LICENSE_SCOPE_codex.md).

The original code is distributed over dated dependency directories. Begin with the public wrapper and source manifest; avoid renaming/moving modules without verifying all path-based imports and the integration tests.
