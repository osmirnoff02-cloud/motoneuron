# Contributing

Please open an issue with the project version, OS/Python/dependency versions, exact command, configuration and a minimal reproducible observation. Do not attach patient records, private correspondence or confidential datasets.

For scientific changes, distinguish publication data, source-cell transfer, numerical results and hypotheses. Record units, species/cells, provenance, uncertainty and the predicted consequence before testing. Include negative outcomes. Numerical balances and human calibration are separate tests.

Keep each new output in a new directory. Preserve earlier source/result provenance, checkpoints and scientific disagreements. Do not silently change a historical default or relabel a scenario grid as a measured interval. Submit original contributions for releases from 0.2.0 under the Motoneuron Noncommercial Research License 1.0, with appropriate attribution and permission to contribute. Contributors retain their rights: a submission does not automatically transfer copyright or permit the maintainers to commercially license that contribution. Obtain explicit additional permission before including others' contributions in a commercial license. External code retains its original terms; do not import code whose license conflicts with this distribution. Changes to the historical 0.1.2 AGPL version remain subject to its terms. See [licensing scope](docs/LICENSE_SCOPE_codex.md).

The original code is distributed over dated dependency directories. Begin with the public wrapper and source manifest; avoid renaming/moving modules without verifying all path-based imports and the integration tests.
