# Parameter inventory

[Home](../README.md). Codex, 2026-11-13.

[JSON](registry_codex.json) retains structured numeric values and code provenance; [CSV](registry_codex.csv) is a readable flat view. This is a filtered export of the canonical local registry, restricted to entries with a source in the exported runtime. Correspondence/contact fields were excluded. The original registry hash is in the JSON.

The inventory is not a complete certificate of calibration: implicit constants may not be captured, units can remain unresolved and historical grids are not active defaults. The selected C08 declaration is in `data/2026-11-13-joint-kcnq-pump-v2/declared_candidates_codex.json`; list index 8 is C08. Actual reconstructed options are recorded in each run's configuration. Do not edit generated CSV and JSON independently.
